# Roadmap

## v0.1

- deterministic offline workflow;
- strict contracts;
- fixture-based evaluation;
- safe persistence and audit evidence;
- CLI and optional API;
- reviewable release artifacts.

## After external review

- one real pilot with sanitized or synthetic customer-owned data;
- one narrowly scoped enterprise connector;
- reliability fixes based on pilot evidence;
- stable v0.1.0 release.

## Explicitly deferred

- hosted control plane;
- multi-region deployment;
- generic plugin marketplace;
- autonomous high-impact actions;
- broad connector catalog.
